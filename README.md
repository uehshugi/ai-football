# Тактический конструктор
Учебный проект — статический сайт, работает без сервера.

## Как запустить локально
1. Скачай все 4 файла в одну папку
2. Открой `index.html` в браузере

## Деплой на GitHub Pages
1. Создай репозиторий `https://github.com/твой-логин/tactics-builder`
2. Залей все файлы
3. Settings → Pages → Source: `main` → Save
4. Через 2 минуты открывай `https://твой-логин.github.io/tactics-builder/`

## Что внутри
- 4 схемы (4-4-2, 4-3-3, 3-5-2, 5-3-2)
- Расстановка игроков кликами по полю
- Автоматический разбор (без API — встроенные правила)
- Адаптив под телефон
